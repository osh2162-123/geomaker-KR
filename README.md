# 지리 자료 제작기

시험지 양식의 백지도(세계·한국), 지형 모식도, 기후·에너지·종교·인구·농업 그래프를 문장 한 줄로 만드는 지리 수업 자료 도구입니다.
승현이 Claude(Anthropic)와 협업해 만들었습니다.

- 쓰는 법: 이 저장소의 GitHub Pages 주소를 열고, 주소창의 '앱 설치' 단추나 화면 아래 '앱으로 설치'를 누르면 프로그램처럼 설치됩니다.
- 처음 한 번 열면 모든 자료를 기기에 저장해 두므로, 그다음부터는 인터넷 없이도 열립니다.
- 만든 그림과 작업 파일은 각자의 기기에만 저장됩니다(서버로 보내지 않음).
- 자료 출처와 라이선스: licenses.html
- 이 판에는 한국교육과정평가원 시험지의 지형 모식도가 들어 있지 않습니다.
